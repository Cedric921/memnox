The voice takes the person's name out of a reply only where it calls them, at the end of a clause or the start of a sentence, so "assigned to Moise, and nothing matches" is said whole rather than as "assigned to and nothing matches". A resumed voice is told which drafts it put up were sent, failed, declined, withdrawn or ran out since the person last spoke, so a draft already sent is never called waiting on their screen. The `repository` tool finds a repository named out loud on the disk when no session touched it in the last day, rather than reporting it missing, and its description no longer offers a real project name as the example.
