GitHub Copilot CLI, Devin and OpenCode are hooked by setup and found by scan, as Gemini CLI and Windsurf now are too. Claude Code's hook stands down where Cursor, Devin or Copilot runs it, so no call is ruled twice or filed under the wrong agent, and doctor says when Codex no longer runs a Memnox hook it once trusted. Every agent's hook and plugin runs through one launcher at a fixed path, so an update to Memnox never sends Codex's hooks back for approval, and the launcher and the daemon run on a Node of the person's own before one another app bundles. Setup ends with what only the person can do, such as approving hooks in Codex or restarting an agent that loads a plugin, and doctor tells a terminal older than its PATH from one that is missing it. The daemon's home carries the same list as needsYou, each item kept until the ledger hears from that agent after the change, so the Mac app says what setup could not when it ran without a terminal. Doctor counts MCP servers the way mcp wrap acts on them, so Memnox's own servers and those declared by URL no longer read as unrouted.
