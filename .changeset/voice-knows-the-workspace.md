The voice reads what the workspace lets this Mac read: its name, its Slack and Discord messages and its Linear, Jira and GitHub tickets. Asked to have an agent implement a ticket, it gathers the ticket, what was said about it and the decisions that bind it into a brief the agent reads through the new `work` session tool, told to keep to every decision and to ask when one disagrees with the ticket. Workspace memory is pulled fresh before it is read, and the voice never reads an id aloud.
