Hermes sessions now show beside the others on the phone and the Mac, read from Hermes's own database without writing to it: what each is on, where it works, and its latest conversation, so on a server where Hermes runs you can see what it is doing and ask what it found. An instruction for a Hermes session starts Hermes on that session from its own command line, so it reaches the agent with no Mac to type into it. A held call now carries the name of the rule that asked, so the workspace can put it to that rule's approvers, and an enrolled machine keeps the person who owns it.
