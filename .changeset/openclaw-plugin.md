Setup writes a Memnox plugin into OpenClaw that hands every tool call and session to the policy hook, so OpenClaw is ruled on, takes leases and reaches the ledger. A relative path is resolved against the directory OpenClaw itself resolves it in, an ask goes to its person through OpenClaw's own approval and a no or a timeout there is recorded, and a config written as JSON5 is joined with marked insertions that keep every comment.
