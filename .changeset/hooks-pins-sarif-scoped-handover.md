Scan counts the hooks every agent here runs on its own events, including those an enabled Claude Code plugin brought, and a new hook is drift with its own alert and notice. A server fetched by `npx` or `uvx` without an exact version is named as unpinned. `scan --sarif` writes a comparison as SARIF 2.1.0 for code scanning. A rule handed over from `memnox next` names only the targets that were approved, and an action is judged by the widest class it was recorded under.
