The voice waits for a person to finish. A new `keep_listening` operator tool lets the brain stay silent when somebody stops mid thought, rather than answering half a sentence. `changes` gives every file a kind and lists the interface files, so a question about the UI is answered from the screens that changed. The voice no longer reads tool labels aloud, checks the record before saying there are no issues, never answers a complaint defensively, and picks up where it left off when told it went quiet.
