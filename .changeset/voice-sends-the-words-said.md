An instruction reaches the agent in the person's own words, read back once, and to the session as it is now. The brain passes on exactly what was asked, fixing only misheard names, and calls its tool before it speaks so nothing is said twice. Typing into a terminal and bringing a session forward use the terminal its process holds now, and a session whose process has ended is never typed into.
