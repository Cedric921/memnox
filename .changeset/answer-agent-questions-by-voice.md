An agent you start by voice that stops to ask something in its terminal before it starts, such as Claude Code asking whether you trust the folder, is no longer left waiting in silence: the voice reads its tab, says what it asks and the choices, and presses the keys for your answer in that tab and nowhere else. The same works for any question an agent shows in its terminal later. A repository, folder or agent you name is the one used, never one you use more often, and a name that only sounds like a repository is read back to you rather than started. A permission or a choice Claude Code asks for in the middle of a session is read out the moment it is asked, and answered the same way. The voice finds the person you mean by name in the workspace before it sends them anything, says the name of the workspace it is connected to after a login, and tells you when this Mac is enrolled in a different workspace from the one you signed in to, rather than reporting an empty memory. As an admin you can read through a tool you connected for the workspace without signing in again; sending still goes out under your own sign in. The VS Code extension is installed again whenever what it declares changes, not only its code, so it runs in every window and the window holding a session's terminal answers when words are typed into it.
